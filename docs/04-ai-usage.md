# AI 使用记录

本项目开发过程使用了 AI 辅助，以下如实说明。当前版本的需求拆解、设计、代码、测试、在线运行和文档主要由 Codex 辅助完成；项目作者选择了企业知识问答方向与 LangGraph 路线，提供 DeepSeek 接入信息并在本机 `.env` 配置密钥。Codex 执行了六个在线场景与资料替换实验，保存实际输出，并根据独立代码审查修改了回答约束、输出 schema、Trace 与文档。早期 AI 辅助开发时段约为北京时间 2026-11-01 15:33–16:00；项目作者本人的实际投入时间需另行记录。

目前能确认的项目作者个人贡献是选择项目方向与技术路线、提供接口条件并配置本机密钥。发布前应补充：亲自修改的具体文件与原因、亲自执行的命令和观察结果、实际用时、仍未完成的部分。不得把 Codex 生成或执行的内容写成作者亲自完成，也不要把仅运行 Mock 的结果描述为模型决策效果。不要提交密钥。

用户追问冲突路径和真实企业杂乱文档的适配后，Codex 又补充了“仅有 D01”的在线对照运行、对应自动校验和扩展设计文档。随后用户指定参考 [GiovanniPasq/agentic-rag-for-dummies](https://github.com/GiovanniPasq/agentic-rag-for-dummies)。Codex 阅读该项目的 MIT 许可与摄取、分块、向量库模块，借鉴父子分块及 dense/sparse 混合检索思路，重新编写 PDF/Markdown 摄取、Qdrant 本地索引、检索评估和测试；未复制源文件。新增代码、文档、测试、真实模型 Trace 与评估均由 Codex 辅助完成。项目作者须自行复核后据实补充个人修改、运行和用时。

用户随后要求以短视频工具企业为场景拟制知识库。`data/video_tool_kb/` 的制度、产品能力、日期、流程和数字均由 Codex 合成，未经小影科技验证，不可视为真实公司资料。对应标注查询、索引运行、真实模型调用、失败记录、测试与评估文档也由 Codex 辅助生成及执行。

2026-11-03 用户指出在线输出、答案可读性与评测规模问题后，Codex 编写了格式解析与一次修复、引文选句、30 份额外模拟业务记录及 50 条进阶标注查询，并运行离线测试和检索评测。在线复测遇到 DeepSeek HTTP 503，未获得新版本成功率。新增工作仍属 AI 辅助；项目作者个人修改和复核情况须如实补充。
