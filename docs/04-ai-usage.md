# AI 使用记录

本项目允许 AI 辅助，但须如实说明。当前版本的需求拆解、设计、代码、测试、在线运行和文档主要由 Codex 辅助完成；用户选择了题号 3、LangGraph 路线，提供 DeepSeek 接入信息并在本机 `.env` 配置密钥。Codex 执行了六个在线场景与资料替换实验，保存实际输出，并根据独立代码审查修改了回答约束、输出 schema、Trace 与文档。AI 辅助开发时段约为北京时间 2026-11-01 15:33–16:00；考生本人的实际投入时间需另行记录。

目前能确认的考生个人贡献是选择题目与技术路线、提供接口条件并配置本机密钥。提交前由考生补充：亲自修改的具体文件与原因、亲自执行的命令和观察结果、实际用时、仍未完成的部分。不得把 Codex 生成或执行的内容写成考生亲自完成，也不要把仅运行 Mock 的结果描述为模型决策效果。不要提交密钥。

用户追问冲突路径和真实企业杂乱文档的适配后，Codex 又补充了“仅有 D01”的在线对照运行、对应自动校验和扩展设计文档。这部分同样属于 AI 辅助工作，尚未实现通用文档摄取或向量检索。
