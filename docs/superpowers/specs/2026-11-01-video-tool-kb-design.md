# 短视频工具企业模拟知识库设计

## 目的

为企业知识问答 Agent 提供更接近业务的合成资料，使检索、引用、资料不足、冲突和版本处理可以在跨部门场景中演示。所有内容均为虚构设定，不代表小影科技真实产品功能、制度或服务承诺。

## 方案

沿用项目已经支持的 Markdown 原文件和 `.meta.json` 侧车：按产品、内容安全、发布、客户服务、数据与内部协作编写多个短文档；每份有稳定 ID、主题、版本日期、适用范围，正文有负责人、规则、例外或升级路径。另放两份无明确优先级的冲突资料，验证不擅自裁决。提供目录、评测题与本地索引命令。

选择 Markdown 是为了让候选人和评审直接审阅、修改原文，并复用现有摄取管线。PDF 解析能力继续由现有测试覆盖；本知识库暂不模拟扫描件、ACL 或历史文档权限。

## 成功标准与边界

能从新目录建索引；标注查询可召回相关文档；明确问题有原文引用，冲突问题列双方，资料外问题说明缺口；替换资料后重建索引会更新答案。虚构数字仅用于演示，不能在对外材料中作为实际公司承诺。
